# ✉️ Remember-Server
상실을 기록하고 치유를 도와주는 감정 기반 심리케어 앱

## 🕊️ About Remember
세상을 떠난 반려동물, 친구, 가족 등 소중한 존재에게 편지를 쓰면서  
감정을 자연스럽게 표현하고 심리적으로 안정을 찾을 수 있는 공간을 제공합니다.

## ✨ Commit Convention

| 이모지 | 태그 | 의미 |
|--------|------|------|
| 🎉 | `init` | 프로젝트 초기 세팅 |
| ✨ | `feat` | 새로운 기능 추가 |
| 🐛 | `fix` | 버그 수정 |
| ♻️ | `refactor` | 코드 구조 개선 |
| 📝 | `docs` | 문서 수정 (README 등) |
| 🔥 | `remove` | 불필요한 코드/파일 삭제 |
| ✅ | `test` | 테스트 코드 작성/수정 |
| 🚀 | `deploy` | 배포 설정, 버전 릴리즈 |
| ⬆️ | `chore` | 패키지 업데이트, 설정 파일 변경 등 |
